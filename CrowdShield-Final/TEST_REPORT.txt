LIMITATION OF THIS TEST ENVIRONMENT
-----------------------------------
The container's Chromium is administratively blocked from navigating to local/file URLs, so a full browser+CDN end-to-end playback test could not be executed here. The core JS modules and data-flow logic were tested independently, and all static/syntax/DOM checks passed.

IMPORTANT
---------
No software change can make COCO-SSD perfect in extreme dense occlusion. This build mitigates the failure mode by improving recall and, crucially, refusing to convert weak perception into a confident SAFE output. For production dense-crowd perception, upgrade the detector/tracker to YOLO + ByteTrack and calibrate venue geometry.
